أداة WormGPT هي أداة تساعدك على إنشاء أدوات غير أخلاقية بأي لغة برمجة، وتساعدك على القيام بأي عمل غير أخلاقي. أنت غير مسؤول عن أي استخدام خاطئ لهذه الأداة.

#### تم اختباره على:

* كالي لينكس

* بلاك آرتش لينكس

* كالي نيثنتر

* Termux (للأجهزة ذات صلاحيات الروت/بدون صلاحيات الروت)


### تثبيت

```
تحديث الحزمة وترقية الحزمة -y
```
```
pkg install git -y
```
```
pkg install python3
```
```
git clone https://github.com/black-demon-dr7/WormGPT.git
```
```
قرص مضغوط WormGPT
```
```
pip install -r requirements.txt
```
```
chmod +x *
```
```
python3 WormGPT.py
```
